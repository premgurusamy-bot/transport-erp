# API documentation

Interactive docs (Swagger UI): **`/api/docs`** on any running server; machine-readable spec: `docs/openapi.json` (also `/api/openapi.json`).

## Conventions
- Base path `/api/v1`. JSON in/out. Money values are exact decimal **strings** (e.g. `"30000.00"`). Timestamps ISO-8601 UTC.
- Authentication: `Authorization: Bearer <token>` from `POST /auth/login` (password) or `POST /auth/otp/verify` (drivers). Tokens are revocable server-side sessions.
- Optional header `X-GRL-App: web|portal|driver|management` (used by the AI gateway to enforce which assistant is available in which app).
- Errors: `{"error": {"code", "message", "details"}}`. `401` sign-in needed · `403` permission/self-approval · `404` not found or not yours (tenant isolation) · `409` conflict/duplicate · `422` validation or a business/legal/safety gate (details list each failed check) · `429` rate-limit/lockout/AI budget.
- Every request is permission-checked on the server; hiding a button in the UI is never the control.
- Idempotency: payments (`idempotency_key`), package scans and offline events (`client_event_id`) can be safely retried.
